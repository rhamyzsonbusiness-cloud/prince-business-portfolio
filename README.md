# Prince Hintapa — Independent Portfolio

A mobile-first, interactive portfolio for business operations and growth support. Created as standalone source code to avoid incremental Lovable AI credits or hosting dependency.

## Files
- `index.html`: main portfolio and accessible interactive examples
- `styles.css`: responsive visuals, scroll reveals, microinteractions and reduced-motion support
- `script.js`: menu, scroll progress, intersection reveals, and interactive sample workflow
- `resume.html`: public resume view without home address, birthday or private phone number
- `.nojekyll`: GitHub Pages static deployment compatibility

## Local preview
Run `python -m http.server 8000` in this folder, then open `http://localhost:8000/`.
No install, build process, account key, backend, or paid services required.

## GitHub Pages
Deploy from the root of `main` through Repository Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)`.

## Content boundaries
- Work examples are team contributions and illustrative workflow demos. They do not represent confidential CRM records, performance guarantees or independently deployed automation.
- Do not upload confidential company records, customer data, credentials, personal address or date of birth.
- External fonts have system fallbacks; core experience works without them.
